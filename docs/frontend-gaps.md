# 前端缺口分析（backend capability vs frontend usage）

> 目标：盘点主进程/Preload 已具备能力是否在前端落实，以及 PRD（docs/requirements.md）中尚未落实到前端的 P0/P1 功能。

## 1. 已修复的前端阻塞（2026-09 检查）

| 组件 | 问题 | 修复 |
| --- | --- | --- |
| 详情页「添加标签」按钮 | 无 onClick，点击无响应 | 改为可交互 TagEditor：新增标签（提交/保存）、删除标签 |
| 快捷入口「生成 AI 摘要」 | 死按钮 | 改为本地智能摘要：读取 README 标题 + 结构分析语言 + 最近提交 + 磁盘大小，写入项目 summary，并提示未发送外部 |
| 任务中心「运行记录」 | 无停止按钮、状态不刷新 | 增加停止按钮（tasks:stop）+ 2s 轮询刷新运行状态/输出 |
| 顶栏「⌘ K 快速查找」 | 提示存在但快捷键无响应 | 支持 Ctrl/Cmd + K 聚焦项目搜索框（与 `/` 一致） |
| README 查看器 | 纯文本无排版 | 新增安全 Markdown 渲染（escape 后转 HTML：标题/粗体/代码块/列表/链接） |
| 打开 VS Code/Cursor/终端 | 静默失败无反馈 | `where` 检测命令是否存在，缺失时报错；新增 openPath 打开资源管理器 |
| 详情页「项目概览」回形针按钮 | 死按钮 | 改为在资源管理器中打开项目目录（shell:openPath） |

## 2. 后端已具备但前端未充分使用

| 能力 | Preload 方法 | 前端落地情况 |
| --- | --- | --- |
| `openInEditor(newWindow)` | ✓ | 前端只用了 current window，未暴露「新窗口」入口 |

| branch ahead/behind/remote | ✓ | 分支列表已展示 |
